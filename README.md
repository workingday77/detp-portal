# 신규입사자 온보딩 포털 (dept-portal)

OO그룹 인사팀(가상)의 신규입사자 온보딩 포털입니다. 사내 AI 교육(바이브 코딩) 실습으로 만든 교육용 예시이며, 회사명·조직·제도·수치는 모두 가상의 예시입니다.

## 폴더 구성

```
부서포털/
├─ index.html      포털 본체 (이 파일 하나로 동작)
├─ files/          자료실 파일 (영문 소문자 + 하이픈)
│  ├─ onboarding-guide.pdf   신규입사자 온보딩 가이드
│  ├─ culture-guide.pdf      조직 소개와 인재상
│  └─ systems-guide.pdf      사내 시스템 사용 안내
└─ README.md       이 설명서
```

`이전버전/` 폴더는 작업 기록용 원본입니다. 공개 저장소에는 올리지 않습니다.

## 포털에서 할 수 있는 일

- **체크리스트**: 입사 첫날·첫 주·첫 달 할 일을 체크하고 진행률을 확인합니다.
- **조직 소개**: 6개 부문의 역할, 인재상, 일하는 방식을 봅니다.
- **사내 시스템**: 그룹웨어, 근태, HR 셀프서비스 등 6가지 사용법을 단계별로 봅니다.
- **Q&A 게시판**: 예시 질문과 답변을 검색하고 질문을 남깁니다. 서버가 없어 작성한 글은 그 브라우저에만 저장됩니다.
- **FAQ**: 자주 묻는 질문 10개를 검색하거나 카테고리로 골라 봅니다. 답변마다 근거 자료를 표시했습니다.
- **자료실**: files/의 PDF 3종과 체크리스트·빈 양식을 내려받습니다.
- **다크 모드**: 오른쪽 위 버튼으로 라이트/다크를 바꿉니다.

## 고칠 때 지킬 규칙

- 파일 이름은 한글·공백·괄호 없이 영문 소문자와 하이픈만 씁니다. (예: `채용 공고(최종).pdf` → `recruit-notice.pdf`)
- index.html 안의 자료 링크는 `files/파일명` 형태의 상대 경로로 씁니다. 맨 앞에 `/`를 붙이지 않습니다.
- 실명, 연락처, 급여, 사번 등 개인정보와 공개 승인되지 않은 사내 자료는 넣지 않습니다.
- 디자인은 '우리 부서 포털' 디자인 시스템(색·글꼴·여백)을 따릅니다.
